Esta versión consulta velas OHLC de Twelve Data y aplica reglas técnicas sencillas. La respuesta del proveedor no garantiza que el precio, la latencia o el horario coincidan con Quotex u otra plataforma. La etiqueta “mercado real” se valida con los metadatos recibidos, pero no demuestra equivalencia con el broker.

Una señal CALL/PUT es solo una lectura técnica experimental, no una predicción segura ni una recomendación financiera. Prueba primero en demo y registra resultados. Si la API no responde, los datos son insuficientes o la tendencia no coincide, el sistema bloquea la señal.

Seguridad: para publicar esta aplicación en internet, primero hay que mover la clave API a un backend privado. No uses esta versión cliente con una clave que no quieras exponer.
